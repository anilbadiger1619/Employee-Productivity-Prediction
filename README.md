# Employee Productivity Prediction

## Project Description

Employee Productivity Prediction is a Machine Learning project that predicts an employee's productivity score based on different employee-related factors.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML
- CSS
- Joblib

## Machine Learning Algorithm

Linear Regression

## Input Features

- Working Hours
- Attendance
- Tasks Completed
- Experience
- Overtime Hours
- Leave Days
- Job Satisfaction
- Previous Performance

## Output

The system predicts:

- Productivity Score
- High Productivity
- Medium Productivity
- Low Productivity
